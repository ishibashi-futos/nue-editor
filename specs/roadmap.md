# Product Roadmap

## v1

Goal: 基本的なエディタ機能・ワークスペース機能・エディタとしての高度なUXの提供

- [ ] Workspaces
  - [ ] アプリケーションを起動し、複数のワークスペースを `+` ボタンから追加できる
  - [ ] ワークスペースを右クリックして、選択したワークスペースを除外できる
  - [ ] `Workspace Rail` 上で Busy / Waiting / Error / Idle のライブステータスを視覚的に判別できる
- [ ] Design System
  - [ ] 「Neon-Night-Glass」テーマを `nue-ui` のデザイントークンとして定義し、カラーパレットを一元管理できる
  - [ ] Glass 質感（Backdrop Blur / Fine Grain / Specular Edge）を `Command Hub` と主要パネルに適用できる
  - [ ] Agent Status（Busy / Waiting / Error / Idle）の色とアニメーション規約を UI 全体で統一できる
  - [ ] 未承認/承認済み差分の色規約（`Solar Flare` / `Electric Lime` / `Cloud White`）を Gutter と承認 UI に反映できる
  - [ ] `JetBrainsMono-Regular/Bold/Italic` を埋め込み、`FontContext` で登録・フォールバック追跡できる
  - [ ] UI オーバーレイのスタッキング・コンテキスト（`Command Hub` > `Smart Gutter` > `Decoration` > `Minimap`）を `focus_id` と連動して制御できる
- [ ] Editor
  - [ ] ワークスペース内の`Legacy View`ファイルツリーが閲覧できる
  - [ ] ファイル編集
    - [ ] ファイル選択でエディタ画面が開き、表示・編集・保存、Undo / Redo など基本的なエディタ機能が利用できる
    - [ ] ショートカットキーが利用できる
      - [ ] `Cmd/Ctrl + S` 保存
      - [ ] `Cmd/Ctrl + Z` Undo
      - [ ] `Redo`（macOS: `Cmd + Shift + Z` / Windows: `Ctrl + Y`）
      - [ ] `Cmd/Ctrl + P` で Quick Open
      - [ ] `Cmd/Ctrl + F` でファイル内検索
      - [ ] `Cmd/Ctrl + Shift + F` でグローバル検索
      - [ ] `PgUp`, `PgDn`, `Home`, `End` でカーソル移動
    - [ ] 右クリックメニューから、基本的なエディタ機能が利用できる
    - [ ] Markdown Editに対応した各種機能
      - [ ] Markdownに対応したシンタックスハイライトが適用される
      - [ ] リスト・インデントの自動補完
      - [ ] ペア補完（[ を打つと自動で ] が、( を打つと ) が入力される）
      - [ ] リンクを `Cmd/Ctrl + click` で開く機能
      - [ ] Markdown Previewとのスクロール同期
      - [ ] Markdown Preview上の見出し選択で本文へジャンプ
      - [ ] リンク切れ・画像解決失敗をインライン表示
    - [ ] `Minimap` の表示と、`git` のdiff表示
      - [ ] `Minimap` のクリックで該当行へジャンプできる
      - [ ] 検索ヒット行のハイライトが本文と `Minimap` で同期される
      - [ ] `Shadow Buffer` 差分・`git diff`・検索結果・ビルド/LSPエラーをオーバーレイ表示できる
      - [ ] AI 差分と Git 差分を色・線種で区別して表示できる
      - [ ] `focus_id` を起点に `Command Hub` / `Structure Path` とハイライト同期できる
    - [ ] `Smart Gutter` の表示
      - [ ] `git diff` 種別（追加/変更/削除）を即時判別できる
      - [ ] 変更行へワンクリックで移動できる
      - [ ] AI 差分（pending / accepted / denied / partial）を色とアニメーションで判別できる
      - [ ] インジケーター操作で `Command Hub` の該当 Approval Request を開ける
      - [ ] `focus_id` 更新時に `Minimap` / `Structure Path` と 50ms 以内で状態同期できる
  - [ ] View
    - [ ] ファイルの右クリックメニューから、Markdown Previewが利用できる
    - [ ] ワークスペース内の左側バーに、ファイルツリーメニュー、VCSメニュー、検索メニューが表示できる
    - [ ] ワークスペース内で、エディタ・ターミナルを自由に再配置できる
    - [ ] 現在選択しているペインを `Split` できる
      - [ ] `Split Left/Right/Up/Down` の各方向をキーボード/Command Hubから実行できる
      - [ ] 分割直後にアクティブファイルとカーソル位置を維持したまま新規ペインへフォーカスできる
      - [ ] 分割後の各ペインで独立したアクティブタブ/履歴スタックを保持できる
    - [ ] タブ/ペイン管理
      - [ ] タブをドラッグ&ドロップで同一ペイン内並び替え、および別ペインへ移動できる
      - [ ] `Open to Side` で選択ファイルを隣接ペインに開ける
      - [ ] `Move Tab to Next/Prev Pane` でキーボードのみでタブ移送できる
      - [ ] `Close Pane` 実行時に開いていたタブを隣接ペインへ退避し、未保存変更を失わない
      - [ ] タブの `Close Others` / `Close to the Right` / `Reopen Closed Tab` を実行できる
    - [ ] タブの並べ替え（ドラッグ&ドロップ）ができる
    - [ ] タブのピン留めができる
      - [ ] ピン留めタブはペイン先頭に固定され、通常タブと分離表示できる
    - [ ] ペインごとに「直前ファイルへ戻る」ができる
    - [ ] アプリ再起動時にタブ/レイアウトを復元できる（最低1セッション）
      - [ ] ペイン分割構成、各ペインのアクティブタブ、タブ順序、ピン状態まで復元できる
      - [ ] 復元失敗したファイルは理由付きで通知し、残りのレイアウト復元を継続できる
    - [ ] ファイルペインの上部に、 `Structure Path` が表示される
      - [ ] セグメント単位で Agent Status / 差分状態のマーキングを表示できる
      - [ ] クリックとショートカット（`Alt+1`〜`Alt+5`）で対応箇所へ遷移できる
      - [ ] `Command Hub` の Backoff 状態と同期し、再評価中表示を出せる
  - [ ] Search
    - [ ] ワークスペース内のコンテンツをグローバル検索できる
    - [ ] ワークスペース内のコンテンツの検索に、正規表現が使用できる
    - [ ] `.gitignore` に指定したファイルを検索から除外でき、検索から除外するかどうかトグルで選択できる
    - [ ] 検索から除外するフォルダ、ファイル名を正規表現で決定できる
    - [ ] 検索結果の `Enter` で該当行へジャンプできる
    - [ ] `F4` / `Shift + F4` で次/前の検索結果へ移動できる
  - [ ] VCS
    - [ ] ファイルツリーに `git` の変更状況（Untracked, Modified, Deletedなど）が閲覧できる
    - [ ] ワークスペース内のリポジトリの検出と表示ができる
    - [ ] 選択されているリポジトリのワークスペース内の変更の一覧表示ができる
    - [ ] 選択されているリポジトリのコミットログの表示ができる
- [ ] Terminal
  - [ ] ワークスペース内でターミナルが起動できる
  - [ ] `PTY` ベースでターミナルセッションを管理し、ユーザー操作と `run_command` が同一シェル状態を共有できる
  - [ ] ターミナルにデフォルトシェルの環境変数などが展開されており、`mise` などによってインストールされたツールが使用可能
  - [ ] スクロールバックを最低 500 行保持し、キーボード/マウスで遡って閲覧できる
  - [ ] 全角/半角や Unicode 統合文字列を含む出力でも、列揃えが崩れず表示できる
  - [ ] 同一 `Workspace Session` での `run_command` 同時実行を防ぎ、FIFO キューで順次実行できる
    - [ ] `Running` 中に到着した要求は `Queued` として待機表示できる
    - [ ] `tool.execution.queue_max_pending` を超える要求は拒否し、理由を UI で表示できる
    - [ ] 先行コマンド完了時に、待機中の先頭コマンドを自動実行できる
  - [ ] `run_command` の状態（`Running` / `Queued` / `Completed` / `Failed`）をターミナル上で視覚的に判別できる
  - [ ] `run_command` の CWD を `workspace_root` に固定し、境界逸脱を拒否できる
  - [ ] `workspace_env` に基づく環境変数注入制御を行い、未許可の追加/上書きを防止できる
  - [ ] `run_command` の実行結果（成功/失敗）をターミナル出力と連動して通知できる
  - [ ] キュー遷移/拒否/中断を `Audit Event` として記録し、Terminal UI と監査表示が一致する
- [ ] Command Hub
  - [ ] `Cmd + Shift + P` （Windowsでは、`Ctrl + Shift + P`）でコマンドパレットを開くことができる。
  - [ ] コマンドパレット以外をクリックすると、コマンドパレットは非表示となる
  - [ ] コマンドパレット起動中に `ESC` を押すと、コマンドパレットは非表示となる
  - [ ] `>`: Action Mode Command List
    - [ ] コマンド構文を `> Domain: Verb [Target]` で統一する（例: `> Pane: Split Right`）
    - [ ] `domain` / `verb` / `target` は大文字小文字を区別せず受理し、内部で正規化して解釈できる
    - [ ] `target` を文字列として厳密保持するバイパスを提供する（例: `\"...\"` または `--literal`）
    - [ ] `List` 系コマンドは共通で Picker を開き、`Enter` で実行・`Esc` でキャンセルできる
    - [ ] 破壊的操作（`Workspace Remove` / `Terminal Close`）は確認フロー（確認ダイアログまたは2段階実行）を持つ
    - [ ] `> Workspace: `
      - [ ] `Add`: Workspace のパスを指定し追加できる
      - [ ] `List`: Workspace の一覧を表示する。選択したワークスペースを アクティブにする または escかcancel で取り消し
      - [ ] `Remove`: Workspace の一覧を表示する。チェックボックスを表示し、チェックしたワークスペースを remove または escかcancel で取り消し
    - [ ] `> Pane: `
      - [ ] `Split Left/Right/Up/Down`: 現在選択中のペインを指定方向に分割する
      - [ ] `Next`: 次のペインを選択する
      - [ ] `Prev`: 前のペインを選択する
      - [ ] `Close`: ペインの一覧を表示する。選択したペインを閉じる
      - [ ] `List`: ペインの一覧を表示する。選択したペインをアクティブ化する
    - [ ] `> Panel: `
      - [ ] `Focus Explorer`: ファイルツリーメニューにフォーカスを当てる
      - [ ] `Focus Global Search`: 検索メニューにフォーカスを当てる
      - [ ] `Focus VCS`: VCSメニューにフォーカスを当てる
    - [ ] `> Terminal: `
      - [ ] `New`: 新しいターミナルを作成する
      - [ ] `List`: ターミナルの一覧を表示する。選択したターミナルをアクティブ化する
      - [ ] `Split Terminal`: 現在のターミナルペインを分割できる
      - [ ] `Close`: ターミナルの一覧を表示する。選択したターミナルを終了する（`Kill` はエイリアス）
    - [ ] `> Selected: `
      - [ ] `Open`: エディタ内で選択中の文字列が `https://` で始まる場合は URL として開き、それ以外は path として開く
      - [ ] `Open` 実行時、path/URL の解決に失敗した場合は理由を表示する
  - [ ] `:`: Navigation Mode
    - [ ] `:specs/spec-` のように入力すると、ファイル名に部分一致するファイルを一覧表示できる
    - [ ] 表示されたファイルを選択すると、該当するファイルをエディタで開くことができる
    - [ ] すでに開いているファイルだった場合、該当のファイルがアクティブとして再表示される
- [ ] 性能目標（UX品質）
  - [ ] 起動時間（空ワークスペース）が2秒以内
  - [ ] 10,000行クラスのファイルでもスクロールが破綻しない
  - [ ] 通常操作時（スクロール / Minimap 更新 / 状態アニメーション）で 60fps 相当の描画品質を維持できる
  - [ ] グローバル検索の初回応答が500ms以内（中規模リポジトリ基準）
  - [ ] 大量検索結果表示中でも入力遅延が体感で発生しない
