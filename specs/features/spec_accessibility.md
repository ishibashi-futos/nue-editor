# アクセシビリティ関連の暫定仕様（二次的な記録）

このアプリは開発者個人の利用を想定しており、主要な開発仕様としてアクセシビリティ要件を最優先に据えていません。ただし、過去に議論した色やシンボルへの配慮、アクションの指針などは将来的に参考にできるように `specs/spec_accessibility.md` にまとめることとし、`spec-nue.md` 本体では直接の対応を行わないことを明記しています。

## ステータス表示と差分マーカー

以下は、かつての議論で採用候補に挙がった状態表示とグリフの組み合わせです。現時点では実装の強制ではなく、将来の参考情報として残しています。

| 状態 | 色/外観 | グリフ | 動き・補足 |
| ---- | ------- | ------ | ---------- |
| Busy | Neon Cyan (#00F5FF) | ◇（Diamond）または動的な Aura | ゆっくりパルス／回転で AI 活動中を示す |
| Waiting | Solar Flare (#FFF200) | ▲（Triangle） | 1Hz 程度の点滅で入力待ちを強調 |
| Error | Cyber Magenta (#FF006E) | ✖（Cross） | 高周波の振動/明滅イベントを同期して警告 |
| Idle | Dusty Grey / Cloud White | ○（Circle） | 静止または非常に緩やかなフェードで落ち着いた状態 |

`Smart Gutter` では AI 差分に Solar Flare の縦線、承認済みに Electric Lime のグロー、Git 差分には Midnight Glass 系の図形（追加: 上向き三角、削除: 下向き三角、変更: 横バー）を使い分ける案が検討されました。Git と AI が同一行に存在する場合は AI 表示を優先しつつ、Git の輪郭を残すスタイルです。また `Minimap`/`Structure Path`/`Command Hub` には同一 `focus_id` を共有した差分ハイライトと `Audit Event` 連携が要件として示されていました。

## 高彩度／色覚制限モード（暫定）

* OS 設定や自動検出には依存せず、`nue-config` 側のフラグ (`ui.accessibility.high_contrast: bool`, デフォルト `false`) で制御します。
* 画面内からは `Command Hub` の `Toggle High Contrast Mode` アクションで即時切り替えができ、必要に応じてトリガーを手動でオン／オフします。
* 切り替え時には色だけではなく、`Glyph`（各状態ごとに異なる形状）およびテキストラベル（例: `AI`/`Git`/`Error`）を併用して情報を伝達する方向で検討していました。

## 取り扱いの範囲

現在の開発ではこれらの仕様を強制せず、あくまで「個人が気持ちよく使うための参考情報」として記録しています。将来アクセシビリティの対応が必要になった場合は本稿の内容を起点に再評価してください。
